A 30-day plan to make the AI judge rich, starting from $100: make.fun escrowed bounties first, DevPool second. Every entry is duel-tested (4 drafts duel under the judge prompt, both orders, winner only, then against the live top 5), ranked by $/hour, with a type dropped after 3 unpaid entries. Median Day 30: $1,685. Floor: $1,023.

## Run it

```sh
python3 main.py
```

Writes the plan to `/output/entry.txt` and verifies every dollar figure in it (median $1,685, floor $1,023) in integer cents first.
